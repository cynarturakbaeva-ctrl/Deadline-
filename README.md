# DeadLine v3 — AI Presentation Studio (Telegram Mini App)

Telegram **Mini App** + бот: тақырып/материал/шаблон → кәсіби, **өңделетін** PPTX презентация.

## Режимдер

Mini App-та презентация үшін екі режим (және реферат) бар:

| Режим | Не береді | Нәтиже |
|-------|-----------|--------|
| **✨ AI Presentation** | Тек тақырып немесе қысқа тапсырма | AI құрылым, мәтін, визуал, layout-ты өзі шешеді |
| **🎨 Template → Content** | Дайын шаблон (.pptx) + жаңа тақырып | Шаблонның дизайны (түс, шрифт, макет, құрылым) сақталып, ішіне жаңа мазмұн жазылады |

### Template → Content
- Референс PPTX толық талданады: Design DNA (түс/шрифт/тығыздық) + құрылым (рөлдер, макеттер, тор, қайталанатын элементтер).
- Жаңа контент шаблонның слайд қаңқасы бойынша жазылады; дизайн себепсіз өзгертілмейді.
- **Рендер жоқ**: клиенттің .pptx файлының XML-інде тек мәтін ауыстырылады, сондықтан қораптарды клиент кейін еркін өзгерте алады. Толтыру сәтсіз болса, сурет-слайдқа түспейді — қате қайтарылып, кредит қайтарылады.
- **Мәтін сыйғызу (templateLayout.js)**: мәтін қорапқа сыймаса, бот сатылап әрекет етеді — 1) қорапты бос орынға (төмен/оңға) үлкейтеді; 2) кедергі жасаған элементті (сурет, сызық, сәнді пішін) кішкене (≤0.8″) жылжытады; 3) қаріпті кішірейтеді; 4) ең соңында ғана мәтінді қысқартады. Мәтін мағынасыз қысқармайды.
- Аударудың керегі жоқ: тіл таңдау жасырылған, модель тақырыппен бірдей тілде жазады; міндетті «Кіріспе» слайды қосылмайды.
- Дайын презентацияға `templateQa.js` арқылы Template QA жүргізіледі: слайд саны, рөл реті, макет сәйкестігі, тығыздық, тема — `Template compliance: 6/6 ✓`.

## Файлдарды талдау (толық, filename-ға қарамай)

`POST /api/material` — PDF, DOC/DOCX, PPT/PPTX, TXT, сурет/screenshot (әрқайсысы 50 МБ-қа дейін, бірнеше файл). Мазмұны серверде толық оқылады, preview қайтарылады. Бірнеше файл бір тапсырма контексті ретінде қарастырылады.

## Өңделетін PPTX

HTML клиентке жіберілмейді — ол тек ішкі «сурет салушы». Әр слайд PPTX-те:
- **фон-сурет** (фото, карточка, шкала, декор) — мәтінсіз рендерленеді;
- **нативті мәтін қораптары** — HTML-дегі орны, жолдары, кегль, салмақ, түсімен (`textLayer.js` өлшейді, `pptxExporter.js` жазады).

Мәтін **Calibri** мен **Times New Roman**-да (кез келген PowerPoint / Google Slides-та бар). HTML оларды метрикасы бірдей ашық көшірмелермен (Carlito, Liberation Serif — `assets/Text-*.ttf`, `assets/Serif-*.ttf`, қазақ әріптері толық) өлшейді, сондықтан жол ауысулары PowerPoint-тағымен бірдей. Тексеру тілі блок бойынша қойылады (kk-KZ / ru-RU / en-US). Слайдтың мәтін қабаты алынбаса — сол слайд толық сурет болып қалады.

## Баяндамашы мәтіні және оқу көмекшісі

Слайд мазмұны түпкілікті болған соң, `speakerNotes.js` суреттер жүктелетін кезеңмен **қатар** (күту уақыты қосылмайды) жазады:
- әр слайдқа **басты ой** (бір сөйлем) + **айтылатын мәтін** (60–120 сөз: түсіндіру, мысал, келесі слайдқа көпір) → PPTX «Заметки»;
- **негізгі терминдер** (қарапайым анықтамамен) және **мұғалім қоюы мүмкін сұрақтар** жауаптарымен.

Бәрі бөлек «Баяндама мәтіні» .docx болып (`speechDoc.js`) PPTX-тен кейін чатқа жіберіледі; Mini App-та «🎤 Баяндама» батырмасы. Файл `jobs/<id>/speech.docx`-те сақталады (DB өзгермейді). LLM сәтсіз болса — презентация баяндамасыз жеткізіледі. Шаблон режимінде әзірге жоқ.

## Инфографика кітапханасы

`design/infographics.js` — кодпен салынатын 14 кәсіби компонент (LLM тек дерек береді, сурет әрқашан біздікі):

| Топ | Компоненттер |
|---|---|
| Сандар | `bar`, `column`, `line`, `donut`, `compare`, `pictogram` |
| Құрылым | `cycle`, `funnel`, `pyramid`, `venn`, `matrix` (SWOT), `prosCons`, `roadmap`, `iconGrid` |

- Мазмұн промпты `infographic: {kind, items[{label, value, detail, icon, group}], unit, center, source}` өрісін толтырады; әр түрдің өз тексерісі бар — жарамсыз болса, слайд қалыпты макетке түседі.
- LLM-сіз анықтау: бірдей бірліктегі 4+ сан → `bar`, SWOT буллеттері → `matrix`.
- Дизайн ережесі: бір мән акцент градиентімен бөлектеледі, қалғаны күңгірт; жұқа пішін, жіңішке ось, мән тікелей жазылады. Иконкалар — Lucide (ISC, `design/icons.js`, 105 таңдалған).
- Жазулар HTML мәтін → PPTX-те өңделетін мәтін қораптары; пішіндер фонда.
- Көрме: `node scripts/infographic-gallery.js ./out midnight,blush` — барлық компонент таңдалған тақырыптарда PNG болып шығады.

## Бірінші презентация тегін + «Made in DeadLine»

- Кредиті жоқ, ешқашан сатып алмаған адамға **бір тегін презентация**: тек AI режимі, **≤10 слайд** (серверде қатаң), тәулігіне `FREE_DAILY_LIMIT` (әдепкі 100). Генерация сәтсіз болса — тегін мүмкіндік қайтарылады (`users.free_used`).
- Тегін PPTX-те әр слайдтың оң жақ төменгі бұрышында **«Made in DeadLine»** карточкасы: сілтемесі бар бөлек сурет-нысан (`t.me/<бот>?start=madein`), PowerPoint-та жылжытуға/өшіруге болады. HTML бұл бұрышты бос қалдырады.
- Арна белгісі: `t.me/<бот>?start=<арна>` (madein, tiktok, елші коды…) → `users.source`.
- Админ `/stats`: сурет провайдерлерінің сұраныстары/қалған лимиті/кідірісі, кэш, тегін колодалар, тегіннен кейін төлегендер, арналар.

## Сурет лимиттері (Pexels + Unsplash)

- **Фото жоспары** (`photoPlan.js`): фото тек макеті шынымен фото көрсететін слайдтарға ізделеді (макет өзгермейді); бюджет `PHOTO_BUDGET` (4) / `PHOTO_BUDGET_FREE` (3).
- **Кезек** (`images.js`): әр жолы осы сағатта лимиті көбірек қалған провайдерге барады. Pexels тақырыптары **айлық** лимитті береді (сағаттық ~200-ді бот өзі санайды), Unsplash — сағаттық. Сағаттық 429-дан кейін провайдер ~1 сағатқа, ай таусылса ай соңына дейін кідіртіледі; тегін колодалар ақылыларға резерв қалдырады.
- **Кэш**: іздеу нәтижесі 24 сағ, жүктелген сурет жадта (`IMAGE_CACHE_MB`, 80). Бір фотоға ең көбі `IMAGE_SEARCHES_PER_PHOTO` (5) API сұранысы.

## Pipeline (сапа)

`Тақырып → мазмұн → QC → quality loop → narrative → composition → sources → images → visual SVG → HTML (ішкі) → render QA → Vision Critic → redesign → өңделетін PPTX`

Сапа қақпасы: overflow/бос слайд табылса — толық қайта генерация (1 рет). Екінші сәтсіздік — кредит қайтарылады.

## API (қысқаша)

- `GET /api/me` — пайдаланушы + кредит
- `POST /api/material` — материал жүктеу (PDF/DOC(X)/PPT(X)/TXT/сурет) → `{ materialId, kind, preview }`
- `POST /api/reference` — шаблон PPTX жүктеу → `{ refId, lines, slides }`
- `POST /api/generate` — `{ topic, mode: 'presentation'|'template'|'referat', materialIds?, refId?, requirements?, ... }` → `{ jobId }`
- `GET /api/job/:id` — статус / прогресс / `requirementsReport` / `templateReport`
- `GET /api/job/:id/download/pptx|html|docx`
- `GET /api/history`
- Auth: header `X-Telegram-Init-Data`

## Реферат режимі

Mini App-та «📄 Реферат» таңдалады: тақырып, бет саны (5–30), тіл, титул деректері (университет, факультет, кафедра, топ, қала, орындаған, тексерген).
Нәтиже — Word (`.docx`): титул, мазмұны, кіріспе, тараулар, қорытынды, әдебиеттер. Times New Roman 14, жол аралығы 24pt, жиектері 30/10/20/20 мм, қызыл жол 1.25 см, бет нөмірі төменде ортада.
Бос орын болмауы үшін: тараулар жаңа беттен басталмайды, тақырып беттің түбінде жалғыз қалмайды, көлем сұралған бет санына дәл келтіріледі, соңғы бет толық.
Қосымша npm пакет керек емес (docx файлы өз ішіндегі `products/referat/zipmin.js` арқылы жиналады). Әдебиеттер тізімін қолданушы тексеруі тиіс.


## Railway + PostgreSQL

1. Railway жобасына PostgreSQL қосыңыз (бар болса — сол). Бот сервисінің Variables бөлімінде:
   - `DATABASE_URL` = `${{Postgres.DATABASE_URL}}` (Railway reference)
   - `TELEGRAM_BOT_TOKEN`, `DEEPSEEK_API_KEY`, `WEBAPP_URL` (сервистің домені), `ADMIN_CHAT_ID` және т.б.
   - сыртқы (public) URL арқылы қосылсаңыз және SSL талап етілсе: `DATABASE_SSL=1`
2. Start command: `npm start` (`node server.js`). Health check: `/api/health`.
3. Іске қосылғанда кестелер өздігінен жасалады; бар кестелерде тек жетіспейтін бағандар қосылады — ештеңе жойылмайды.
4. Railway дискі уақытша: дайын файлдар (`jobs/`) қайта deploy-да өшеді. Сақтау керек болса Volume қосып, `JOBS_DIR=/data/jobs` беріңіз.
5. Puppeteer Chrome-ы `.cache/puppeteer` ішіне жүктеледі (`.puppeteerrc.cjs`). Рендер «Could not find Chrome» немесе жүйелік кітапхана қатесін берсе, `PUPPETEER_EXECUTABLE_PATH` арқылы жүйедегі Chromium-ды көрсетіңіз.
6. `package-lock.json` жоқ (ескісі package.json-мен сәйкес емес еді). Жергілікті `npm install` жасап, жаңа lock-ты commit етсеңіз, нұсқалар бекітіледі.

7. Ескі нәтижелер автоматты өшеді: `JOB_RETENTION_HOURS` (әдепкі 48) сағаттан ескі жұмыстар, тарих, дайын файлдар, жүктелген шаблондар мен материалдар — базадан да, дисктен де. Тазалау іске қосылғанда және сағат сайын жүреді. Пайдаланушылар, кредиттер мен чектер өшпейді.

PostgreSQL тесті: `TEST_DATABASE_URL=postgres://... npm test` (тек бос тест базасын беріңіз).


## Серіктес бағдарламасы (30%)

Клиент әкелген серіктес сол клиенттің **әр төлемінен 30%** алады (мәңгі). `PARTNER_RATE` env-мен өзгертіледі (әдепкі 0.3).

- Қолданушы «🤝 Серіктес болу» басады → админге «✅ Рұқсат / ❌ Бас тарту» батырмалары бар сұраныс барады.
- Рұқсаттан кейін ғана пайыз есептеледі (бұрынғы төлемдерге — жоқ). Әр чек бір рет (қайталанбайды).
- Серіктес кабинетінде: сілтеме, баланс, тапқаны, аударылғаны, клиент саны. Төлем кезінде серіктеске хабарлама барады.
- Админ командалары: `/partners` — тізім; `/payout <chatId> <сома>` — Kaspi-мен аударғаннан кейін баланстан алып тастау.
- Қолмен растауда (чек парсингсіз) сома кредит санынан бағамен есептеледі.
- Postgres-те жаңа бағандар (`users.partner_*`) мен `partner_log` кестесі автоматты қосылады; бар деректер сақталады.


## Үйрену жүйесі (шаблондардан)

**Мақсат:** LLM мазмұнды жақсы жазады, бірақ дизайнды нашар салады. Сондықтан бот клиенттер жүктеген шаблондарды
«дизайнер көзімен» оқып, дизайн білімін жинайды. Бұл кезеңде жүйе тек ЖИНАЙДЫ және КӨРСЕТЕДІ — ештеңені автоматты өзгертпейді.

**Келісім.** Mini App-та «.pptx шаблонды таңдау» басылғанда ескерту шығады: дизайн деректері жиналады, мәтін/сурет/файл
сақталмайды, қаламаса — функцияны қолданбасын. «Түсіндім» басылса ғана файл таңдалады (құрылғыда есте сақталады).
Жұмыс `learnConsent: true` белгісімен жасалады; белгісіз жұмыстан ештеңе жиналмайды.

**Оқу** (`design-dna/learnReader.js`, `readTemplate(buf)`): барлығы слайд өлшеміне шаққанда 0..1.
- элемент: түрі (мәтін/сурет/иконка/пішін/сызық/кесте/диаграмма), орны, өлшемі, қабаты, бұрылысы, түсі; мәтін — рөлі
  (тақырып/подзаголовок/мәтін/белгі/сан/қолтаңба/футер), қаріп өлшемі (pt және слайд биіктігіне шаққанда), шрифт пен оның
  класы (serif/sans/display/script/mono), салмағы, туралауы, жол/әріп аралығы, таңба/сөз/абзац САНЫ; сурет — пішіні, кесілуі, векторлығы;
- слайд: фон, шеттер, мәтін/сурет үлесі, типографика сатысы мен иерархия, туралау, бағандар, қайталанатын элементтер, макет қолтаңбасы, рөл/макет түрі;
- шаблон: өлшемі, шрифт жұбы, түстер (рөлімен), тақырып түстері/шрифттері, медианалық типографика мен шеттер.
Canva топтары (масштабталған chOff/chExt) мен layout/master мұрасы ескеріледі. Мәтіннің өзі сақталмайды (тестпен тексеріледі).

**Сақтау** (Postgres немесе JSON): `learn_templates` — шаблон бір рет (sha256 қысқа хэші), қайта жүктелсе `uses+1`;
`learn_uses` — әр қолдану: тақырып, тіл, нәтиже (done/failed), сыйғызу ақаулары, job_id. Клиентке байланбайды (chat_id жоқ),
`JOB_RETENTION_HOURS` бойынша өшпейді. Шаблон файлы бұрынғыдай 48 сағатта өшеді. Өшіру: `LEARN_FROM_TEMPLATES=0`.

**Баға.** Клиент нәтижені қарап үлгеруі үшін бірден сұралмайды: ботта ⭐1–5 сұрауы `RATE_PROMPT_DELAY_MIN` (әдепкі 60) минуттан кейін келеді,
түнде (23:00–08:00, `TZ_OFFSET_MIN`, әдепкі +300 Алматы) — таңғы 10:00-де; кезек БД-да (`rate_prompts`), бот қайта қосылса да жоғалмайды;
Mini App-та бұрын бағаланса, сұралмайды. Mini App-та баға «Тарих» бөлімінде (☆ Бағалау). Пікір ботта Reply арқылы жазылады.
Баға `feedback` кестесінде, `learn_uses`-пен job_id арқылы байланысады.

**Админ:** `/learn` — жиынтық (шаблон/слайд саны, сәтті/құлаған, таза сыйғаны, орташа баға, типографика мен шеттер медианасы,
шрифт жұптары, макеттер, макет отбасылары); `/learn <тақырып>` — ұқсас тақырыптағы бұрынғы жұмыстар (сапасымен).


## Чат және Mini App

Презентация мен реферат **тек Mini App ішінде** жасалады. Чатта: Mini App ашу, кредит сатып алу (чек PDF), есепшот,
реферал, серіктес, көмек. Чатқа жазылған кез келген мәтінге бот Mini App батырмасын жібереді.
«2 адам = 1 кредит» реферал бонусы Mini App-тағы сәтті презентациядан кейін саналады (бұрын тек чатта саналатын).

## Шаблон: соңғы геометриялық тексеруші (QA)

Шаблон толтырылған соң әр слайд `products/presentation/templateCheck.js` арқылы тексеріледі:
мәтін ↔ мәтін, мәтін ↔ «таблетка»/рамка, мәтін ↔ сурет қабаттасуы, сөздің ортасынан бөлінуі, слайдтан шығу.
Ақау болса — мәтін жылжытылады және/немесе кегль кішірейтіледі (ең аз өзгеріс таңдалады).
Шаблонда әуелден бар әдейі қабаттасу ақау саналмайды.

- Әріп ені шаблонға **ендірілген қаріп файлынан** (hmtx) өлшенеді — `embeddedMetrics.js`.
- Мөлдір PNG безендірулер (жарқыл, дақ; мөлдір емес бөлігі <20%) мәтінге кедергі емес — `pngAlpha.js`.
- Ұзын мәтінді қысқарту сөзді ешқашан ортасынан кеспейді.
- Нәтиже логта: `[TemplateQA] ...`; үйрену жүйесіне `fit.qa` болып жазылады, `/learn` көрсетеді.
- Өшіру (тек ақау іздеу үшін): `TEMPLATE_QA=0`.

## Шаблон → Мазмұн v2: қорап рөлдері + слот жазушы

Бұрын шаблонның барлық мәтін қорабы бір жалпақ тізім ретінде LLM-ге берілетін («13 пункт: label ≤27, label ≤13 …»).
Мәзір, логотип, «FILM» батырмасы, «92%», «PRESENTATION BY» — бәрі «пункт» болатын; LLM оны орындай алмай,
мәтін РЕТ бойынша шашылатын (тақырыпша орнына ұзын сөйлем, бос батырмалар, авторлар «START» ішінде).

Енді:
1. `templateSchema.js` — әр қорапқа РӨЛ: `chrome` (әр слайдта қайталанатын мәзір/бренд), `tag` (таблетка сөзі),
   `title`, `accent` (каллиграфиялық сәндік сөз — қаріп стилі `fontStyle.js` арқылы), `subtitle`, `card` (тақырыпша + мәтін),
   `stat` (сан + түсіндірме), `credit` (титулдағы «PRESENTATION BY / NAME»), `body`, `label`, логотип (бас әріп + сөз).
2. Мазмұн генераторы шаблонның ФОРМАСЫН ғана алады (`schemaRuleLine`: «3 карточка, 2 сан…») — фактілерді жазады.
3. `templateWriter.js` — әр қорапқа ЖЕКЕ мәтін (JSON кілті = слот): мәзір/белгі бүкіл презентацияға БІР рет,
   слайдтар 3-тен (құласа — жеке-жеке), тексеру (ұзындық, бос, «…», ағылшын шаблон мәтіні, тіл, сан слотында цифр),
   тек қате слоттар қайта жазылады, соңында детерминді қорғаныс (сөз ортасынан ешқашан кеспейді).
4. Авторлар LLM-сіз: университет — титулдың жоғарғы жолында, «Орындаған/Тексерген» — авторлар орнында, топ — орындаушының астында.
5. Толтыру id бойынша (`fillTemplatePptx(..., { slotFill })`); логотиптегі бас әріп пен сөз арасы жабылады (`closeLogoGap`, `packLogoRow`).
6. Қазақ әрпі жоқ қаріп стиліне сай ауыстырылады: sans → Arial, serif → Times, жазу → Times Italic (жуандық/көлбеулік сақталады).
7. PowerPoint placeholder-лерінің мұраланған орны/кеглі слайдқа жазылады (`phGeometry.js`) — сыйғызу мен тексеру олармен де жұмыс істейді.
8. Тексеруші: шаблондағы әдейі қабаттасудан айтарлықтай КӨП қабаттасу — ақау; маркер шегінісі ескеріледі; көлденең жылжыту.
9. Шынайы баға: `Template health` (түзелмеген ақау, қорғаныспен толтырылған слот) композиция бағасына кіреді.

Схема құрылмаса (сирек) — ескі жол (repair + layout plan) қорғаныс ретінде қалады.
`core/llm.js`: `max_tokens`-қа жетіп кесілген жауап анық танылады (`truncated`), бекер қайталанбайды.
